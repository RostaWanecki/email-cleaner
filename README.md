# IMAP Email Cleaner (rozpracované)

Jednoduchý Python skript pro práci s e-maily přes IMAP (aktuálně testováno na Seznam.cz).  
Projekt je **ve vývoji / rozdělaný** a slouží hlavně k učení a experimentování.

## Stav projektu
🚧 **WORK IN PROGRESS**  
- funkce se mohou měnit  
- kód není hotový ani finálně otestovaný  
- může obsahovat chyby  

## Co skript zatím umí
- přihlásit se k e-mailu přes IMAP
- projít inbox
- rozdělit e-maily do kategorií (SPAM / PRÁCE / ŠKOLA / OSTATNÍ)
- vypsat omezený počet e-mailů
- volitelně je smazat po potvrzení

## Použité technologie
- Python
- IMAP
- python-dotenv

## Poznámka
Projekt je momentálně **rozpracovaný**.  
Pravidla filtrace, bezpečnost i struktura kódu se budou ještě měnit.
